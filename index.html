What bots “want” (in practice)

A compact mental model.

1) A fast boot path. If setup takes longer than a couple minutes, the bot will guess. Guessing breaks builds.

2) A trustworthy test command. Bots prefer deterministic verification. They will stop if tests are flaky.

3) A small safe task. Give “good first issue” that includes reproduction steps, expected output, and file pointers.

4) A map. A short CODEBASE_MAP reduces wasted tokens on directory exploration.

5) Clear boundaries. Explicitly say what NOT to do (no dependency bumps, no formatting, etc.).
